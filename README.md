# UnityGitPractice

Учебный 2D-проект Unity для практической работы по Git:
локальный репозиторий, фича-ветки, Pull Request и разрешение конфликта.

## Как открыть проект
1. Клонировать репозиторий.
2. Открыть папку проекта через Unity Hub (Unity 6000.6.0f1).
3. Открыть сцену Assets/Scenes/SampleScene.unity.

## Как проверить изменения (ветка feature/add-ground)
1. Открыть сцену Assets/Scenes/SampleScene.unity.
2. Убедиться, что в иерархии есть объект Monster4,
   он виден в окне Scene и анимируется в режиме Play.
3. Фон камеры тёмно-зелёный, все монстры хорошо различимы.
